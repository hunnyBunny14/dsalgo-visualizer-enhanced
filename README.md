# 🚀 DS Algo Visualizer (Enhanced)

> An interactive visual platform to learn **Data Structures & Algorithms** with animations.

---

## 🔥 About the Project

DS Algo Visualizer is designed to help students understand complex DSA concepts through **visual animations**.

This is an **enhanced version** of the original project with improvements, optimizations, and future upgrade plans.

---

## ⚡ Features

- 📊 Visual representation of Data Structures
- 🎯 Step-by-step algorithm animations
- 💡 Easy-to-understand UI for beginners
- 🚀 Covers 50+ algorithms

---

## 🧠 Data Structures Covered

- Array, Matrix
- Stack, Queue
- Heap
- Linked List
- Binary Search Tree
- Graph
- Hashing Table
- Disjoint Set

### 🔹 Searching & Sorting

### 🔹 Dynamic Programming

### 🔹 Backtracking
